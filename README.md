Чтобы запустить этот проект локально на компьютере, выполните следующее:
1. Настройте среду разработки python (версия указана в файле runtime.txt).
2. Рекомендуется настроить виртуальное окружение. Для этого в терминале выполните следующие команды:
     python -m venv название_окружения;
     название_окружения\Scripts\activate.
3. Перейдите в желаемую папку и клонируйте git-репозиторий с помощью следующих команд:
     cd путь_к_вашей_папке;
     git clone git@github.com:Artem-Ionov/python.git
4. Установите необходимые зависимости (указаны в файле requirements.txt). Для этого можно выполнить в терминале команду: 
     pip install -r requirements.txt.

Примечания:
1. main.py является главным файлом и необходим для проверки правильности работы.
